## 一、互動與動態清單

## 三、動態規範（建議值，設計時可調整）

| 類型 | 用在 | 建議時間 |
|---|---|---|
| 淡出淡入 | C4 事件敘述 | 200–300ms |
| 線條畫出 | C1 關係線 | 每條 300–500ms，依序出現 |
| 亮暗切換 | C2、C3 焦點 | 150–200ms |
| 位置重排（FLIP） | E3、E4 | 300–400ms |
| 回彈 | C5 節點拖曳 | 彈簧曲線，約 400ms |
| 震動 | B5 答錯 | 約 300ms，左右 3–4 次 |
| 閃動 | B5 答對、D1 交叉連結、B3 追蹤開始的側欄回饋 | 約 600ms，1–2 次 |
| 翻面 | D6、D7 | 500–700ms |
| 自動旋轉 | D6 鏡像對照卡 | 緩慢循環，幅度小 |

- **全域規則**：讀者的系統設定為減少動態（`prefers-reduced-motion`）時，取消自動旋轉、閃動、震動和線條畫出動畫，改為直接切換狀態。
