# 真機檢查清單（T124，手動）

自動測試只跑過桌機版 Chromium（含觸控模擬），下面這些**只有真機才看得出來**。
部署後用 `https://leeyitian.github.io/Draven/` 檢查，每一項記下「通過／不通過＋機型＋瀏覽器版本」。

建議機型：iPhone（Safari，最好兩種螢幕寬）、Android（Chrome）、平板各一次（直放、橫放）。

## 1. 載入與字型
- [ ] 第一次進站：文字先出現再換成正式字型時，頁面不會明顯跳動（伏筆框格會重新對齊）。
- [ ] 網路慢（開飛航再開 Wi-Fi，或 DevTools 節流）時，中文字型載入前後換行不亂。
- [ ] 手機 Safari 的網址列收合／展開時，底部導覽列沒有被蓋住、頁面沒有跳。
- [ ] 有瀏海／底部手勢條的機型：底部導覽列有留安全區，按鈕不被手勢條蓋到。

## 2. 捲動與關係圖（R12）
- [ ] 01–04：關係圖縮放 100% 時，單指在圖上**垂直滑動 = 捲動頁面**（不會被圖吃掉）。
- [ ] 按「＋」放大後，單指拖曳 = 平移圖；頁面不跟著捲。按「重設」回到原位。
- [ ] 雙指縮放關係圖順暢（Android Chrome、iOS Safari 各測）；放開後縮放比例合理。
- [ ] 點節點只會聚焦（不會跳出 Popover）；節點不能被拖走。
- [ ] 事件列橫向滑動順暢；點事件格切換事件；「上一個／下一個」可用。

## 3. 各主軸專屬互動
- [ ] **01 光譜**：手指拖指標，放開吸附到最近立場；點軌道空白處跳到最近立場；垂直滑動仍可捲頁。事件 05 的「見下方 ↓」會先捲到光譜再閃動。
- [ ] **02 比較滑桿**：只有把手可拖；在文字區垂直滑動可捲頁；右拉時整頁變黃變舊，左拉回來變新；窄側不會小於 96px。整頁的泛棕濾鏡不卡。
- [ ] **03**：點層頭收合／展開（300ms 動畫順暢）；「只看地底」可用；被收合層連過來的線改接層頭。
- [ ] **04**：第一次進入有劇透遮罩（頁首留著、底部導覽列仍可用）；按「我準備好了，打開」後遮罩消失。
- [ ] **04 鏡像對照卡與明信片**：**3D 翻面**在 iOS Safari 與 Android Chrome 上正常（背面不透出正面、翻面時不閃爍）；閒置時鏡像卡緩慢左右傾斜、不卡頓；明信片翻面時微微上浮。
- [ ] 開啟系統「減少動態」：鏡像卡不再傾斜、翻面改為淡入淡出；03 收合直接到位。

## 4. 人物誌、Popover、伏筆
- [ ] 人物誌（全版抽屜）：卡片網格、標籤篩選、點卡片進中心視角（膠囊標籤＋連線）、再點展開完整介紹。
- [ ] 點人名／名詞跳出 Popover（手機版是底部面板）；點外面或「關閉」收起。
- [ ] 伏筆：進入 02 時「獲得 N 個新伏筆」出現 3 秒；打開托盤，**點選**關鍵字再**點**頁面上的框格放入；答錯會震動並回托盤。
- [ ] 手機版的伏筆註記列（框格在子句後面的那一行）位置正確、框格沒有蓋到文字。

## 5. 文字保護
- [ ] 長按文字不出現「拷貝／全選」選單；雙擊、拖曳都選不到文字。
- [ ] 右鍵（桌機）或長按圖片不能拖出圖片。

## 6. 其他
- [ ] 直式／橫式切換：版型會在舞台版與流式版之間切換，狀態（目前頁、事件、追蹤）保留。
- [ ] 重新整理與上一頁／下一頁正常；網址 `#/axis/3` 直接開得起來。
- [ ] 重置進度（00 頁底部）：兩步驟確認後，追蹤、伏筆、04 遮罩都回到初始狀態。
