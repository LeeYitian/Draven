# 修改紀錄：方向鍵提示、伏筆連動、托盤說明位置

設計檔：`design/故事導覽 排版規劃.dc.html`。共 5 處修改，以下依畫布位置排列。座標、尺寸都是舞台 px（1440×720）。

## 共用動畫

三種動畫都只用設計系統的色票，加在全域 CSS 即可。

```css
/* 按鍵按壓：往下 2px、陰影消失，再彈回來 */
@keyframes keyNudge {
  0%, 55%, 100% { transform: translateY(0);  box-shadow: 0 2px 0 var(--color-neutral-400); }
  25%           { transform: translateY(2px); box-shadow: 0 0 0 var(--color-neutral-400); }
}
/* 向下箭頭上下浮動 */
@keyframes arrowHint {
  0%, 100% { opacity: .35; transform: translateY(-3px); }
  50%      { opacity: 1;   transform: translateY(3px); }
}
/* 伏筆連動脈衝 */
@keyframes fbPulse {
  0%      { box-shadow: 0 0 0 0 color-mix(in oklch, var(--color-accent) 55%, transparent);
            background-color: var(--color-accent-100); border-color: var(--color-accent); }
  35%     { box-shadow: 0 0 0 8px color-mix(in oklch, var(--color-accent) 0%, transparent);
            background-color: var(--color-accent-100); border-color: var(--color-accent); }
  60%,100%{ box-shadow: 0 0 0 0 transparent; background-color: transparent; }
}
@media (prefers-reduced-motion: reduce) {
  .key-hint, .arrow-hint { animation: none; }
  .fb-linked { animation: none; border-color: var(--color-accent); }
}
```

鍵帽樣式（1–3 共用）：`1px solid var(--color-neutral-400)` 外框、文字 `--color-neutral-800`，水平置中。

## 4. 伏筆框格 ⟷ 側欄「伏筆」按鈕 連動脈衝

- **位置**：§5 情境 B「伏筆托盤」。對象是敘述右側空的「伏筆」框格（3px double），以及側欄的「伏筆」按鈕（56×56）。
- **目的**：兩者同步閃動，讓讀者把框格和側欄的伏筆入口聯想在一起。
- **動畫**：兩個元素都套 `fbPulse 2.4s ease-out`，**必須同一時間開始**（用同一個 class 同時加上去，或用 Web Animations API 設成同一個 `startTime`）。
- **觸發與停止**：
  - 事件中出現還沒填的伏筆框格、而且框格進入可視區時開始。
  - 讀者打開伏筆托盤，或框格被填入後停止。
  - 正式版：播 3 次後停止，之後每 12 秒提示一次。設計稿為了展示所以無限循環。
- **減少動態**：取消外光擴散，框格與按鈕只保留 accent 色外框。
- 設計稿裡情境 B 畫面下方有「動態規格 · 伏筆連動脈衝」區塊，可以看到實際動畫。

## 5. 伏筆托盤：操作說明移到左邊

- **位置**：§5 情境 B，下方伏筆托盤的標題列。
- **原因**：說明原本靠右，桌面螢幕寬，讀者的視線不容易看到。
- **改動**：標題列順序改為
  `伏筆`（標題）→ **說明「拖曳關鍵字到頁面上的框格，或點選關鍵字再點框格」** → 彈性空白 → `已獲得 11 個伏筆 · 已解開 3` → 收合按鈕。
  - 說明 13px → **15px**，色 `--color-neutral-600` → **`--color-accent-800`**。
  - 計數文字移到右邊，樣式不變（13px，`--color-neutral-700`）。
  - 手機版托盤也一樣，說明緊接在標題後面。
